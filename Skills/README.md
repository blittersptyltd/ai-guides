## Skill Quality Standard

Skills in this folder should be:

- **Operational** — written as repeatable workflows, not essays
- **Evidence-backed** — based on real-world implementation experience
- **Reusable** — avoid private paths, credentials, customer details, or one-off task state
- **Agent-friendly** — include trigger conditions, exact commands, pitfalls, and verification steps
